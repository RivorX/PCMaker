# PC model assets

Retrieved 2026-11-05. The source pages below identify these models as CC0 / public domain and allow reuse, modification, and redistribution, including commercial use, without attribution. This records the providers' declarations; it is not an independent review of third-party rights.

## Processing

- GLB files were processed with the official glTF Transform CLI 4.5.1: textures were resized to a maximum of 1024 × 1024 pixels and transcoded to WebP at quality 85. The geometry, materials, nodes, and transforms were preserved except for the CPU extraction described below.
- WebP is declared using `EXT_texture_webp`; the project’s Three.js `GLTFLoader` supports this extension.
- The CPU source combines a processor and a cooler. The final CPU GLB retains only the `Integrated heat spreader` and `Processor package substrate` meshes; cooler meshes were removed, then unused properties were pruned.
- All Innerscene parts are modeled at real-world scale in metres. Grab3D RAM dimensions are also reported in metres.
- The Innerscene provider dimensions and descriptions below use the provider's nominal frame; they are **not GLB coordinate measurements**. The delivered GLBs use local **+Y up**. Bounds in the last column were measured from position accessor bounds after applying the GLB node transforms.
